# Data Skills Atlas · اطلس مهارت‌های داده

What do Iranian employers ask of data roles? An interactive, bilingual (Persian/English) atlas built from a content analysis of job ads for five data-driven roles in Iran, spring 2025 (1404).

This branch (`gh-pages`) holds the static site. It contains **aggregated counts and percentages only** — no ad-level data.

- `index.html`, `style.css`, `app.js` — the site (vanilla JS, no build step)
- `atlas_data.json` — aggregated data generated by the (private) analysis pipeline

Research and data: Fatemeh Teimourpour. Data collected in spring 2025 (1404) for an analytical report by the Tose’e Institute, scientific advisor Dr. Mohammad Mahdi Pourbasir.
